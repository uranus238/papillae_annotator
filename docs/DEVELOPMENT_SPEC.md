# Codex開発指示書：Papillae Annotator

## 1. 開発目的

魚類の頭部sensory papillae（感覚孔器）と解剖学的ランドマークを、顕微鏡画像上で手動記録する研究者向けWebアプリケーションを開発する。

研究者と共同研究者が、同じ定義・操作方法で画像をアノテーションし、分類学・形態学・統計解析に利用できる計数データおよび二次元座標データを効率的に作成することを目的とする。

**アプリ名：Papillae Annotator**

初期バージョンでは手動アノテーションに特化し、画像の自動検出や深層学習は実装しない。

## 2. 技術構成

- React + TypeScript + Vite
- react-konva：画像表示、拡大、移動、アノテーション
- IndexedDB / Dexie.js：ローカルデータ保存
- CSV、JSONによるデータ入出力
- サーバーや外部APIを必要としないローカルファースト設計
- GitHub Pages等で公開できる静的Webアプリ
- UIは日本語を基本とし、将来的な英語化を考慮する

ブラウザ上で動作し、画像や計数データを外部サーバーへ送信せずに利用できること。

## 3. 記録する基本情報

各画像に以下の情報を記録する。

### 必須項目

- ID：個体識別番号（文字列）
- side：LまたはR
- image_id：画像識別番号（自動生成）
- image_filename：元画像ファイル名
- observer：計数者

### 任意項目

- species：種名
- locality：採集地
- SL_mm：標準体長
- HL_mm：頭長
- sex：性別（MまたはF）
- pixel_size_um：1ピクセル当たりの実寸
- notes：備考

sexはM、F、未入力のいずれかを選択できるようにする。未入力の場合は欠測値として扱い、MまたはFの入力を強制しない。

IDとsideの組み合わせで個体の左右を区別する。

同一個体の左右両側を登録でき、同一個体・同一側について複数画像や複数のアノテーションセッションが存在しても管理できる設計とする。

## 4. Papillaeカテゴリ

以下の22カテゴリを初期設定として登録する。

カテゴリは必ず**a系列、b、c系列、その他の4グループ**に分類する。

### Group A：a系列

- a1
- a2
- a3
- a4
- a5

### Group B：b

- b

### Group C：c系列

- c1
- c2
- c3
- c4
- c5
- c6
- c7
- c8
- c9

### Group D：その他

- cp
- d
- x
- z
- os
- ot
- oi

### カテゴリ選択UI

- 4グループすべてのカテゴリボタンを右側パネルに常時表示する。
- 原則としてスクロールやドロップダウン操作なしで全22カテゴリを選択できる配置とする。
- 各グループを視覚的に区切る。
- 各カテゴリは1クリックで選択可能にする。
- 選択中のカテゴリは明確に強調表示する。
- 各カテゴリボタンに現在の計数値を表示する。
- カテゴリごとに識別しやすい色を割り当てる。
- カテゴリ選択後は、別カテゴリを選択するまで同じカテゴリへの連続入力を可能にする。
- 作業を効率化するため、キーボードショートカットによるカテゴリ切り替えにも対応する。
- カテゴリ定義は設定ファイルで管理し、将来的な追加・変更を可能にする。

### Papillae計数機能

- カテゴリを選択し、画像上をクリックすると点を追加する。
- 1クリックにつき1個のpapillaを記録する。
- 同一カテゴリに任意の数の点を記録できる。
- 点のXY座標を保存する。
- 点の大きさ・透明度・表示色を設定できる。
- 点の移動、削除、カテゴリ変更に対応する。
- Undo/Redoに対応する。
- カテゴリ別の表示・非表示を切り替えられる。
- カテゴリ別の計数値をリアルタイムで更新する。

### 自動集計

以下を計算する。

- a_total：a1～a5の合計
- c_total：c1～c9の合計
- papillae_total：全22カテゴリの合計

ただし、未観察カテゴリがある場合、これらは完全な合計値と区別する。

未観察カテゴリを勝手に0として扱わず、観察済みカテゴリのみの小計であることを明示する。

## 5. 欠測値の扱い（重要）

**PapillaeもLandmarkも、すべてのカテゴリの記録を必須にしない。**

画像によって一部の孔器列やランドマークが写っていない、あるいは観察できない場合があるため、欠測を正式に許容する。

### Papillaeの観察状態

各カテゴリについて以下の状態を管理する。

1. 未観察：まだ計数していない
2. 計数中：計数途中
3. 計数完了：観察・計数が終了した
4. 観察不可：画像に写っていない、または判別できない

**未観察・観察不可と、観察済みで0個だった場合を明確に区別する。**

- 計数完了かつ点が0個：計数値0
- 未観察：NA
- 観察不可：NA（状態は別途保存）
- 計数中：暫定値として保持し、正式な集計には未確定であることを表示

カテゴリごとに「計数完了」「観察不可」を簡単に指定できるようにする。

初期状態では、全カテゴリを未観察とする。

### Landmarkの欠測

- 各ランドマークは未記録でもよい。
- 未記録の場合はNAとして出力する。
- 画像に写っていない場合も記録を強制しない。
- 観察不可として明示する機能を用意する。

## 6. Landmarkカテゴリ

以下の9種類を初期設定とする。

1. eye
2. AN
3. PN
4. 吻前端
5. 上唇上端
6. 吻後端
7. 胸鰭基部上端
8. 胸鰭基部下端
9. 第一背鰭前端

### Landmark記録機能

- Landmarkモードに切り替えて記録する。
- カテゴリを選択し、画像上をクリックすると座標を保存する。
- 各Landmarkは原則として1画像・1セッションにつき1点とする。
- 同じLandmarkを再指定した場合は、既存点の移動または上書き確認を行う。
- 点の移動・削除に対応する。
- LandmarkはPapillaeとは異なる記号・表示色を使用する。
- LandmarkはPapillaeの計数値には含めない。
- 共通のLandmark IDを使用し、個体間の対応関係を維持する。
- 全9点の記録を必須にしない。

eyeは初期バージョンでは眼の中心を示す1点として扱う。

### Landmark自動切り替えモード（新規必須機能）

**Landmarkを1点記録すると、自動的に次の未記録Landmarkへ切り替えるモードを実装する。**

動作仕様：

1. Landmarkモードを選択する。
2. 「自動で次へ」機能をONにする。
3. 最初の未記録Landmarkを選択する。
4. 画像上をクリックして記録する。
5. 自動的に次の未記録Landmarkへ移動する。
6. 全9種類の記録が終了したら、完了を表示する。

追加条件：

- 自動切り替え機能はON/OFF可能。
- 順番は上記9カテゴリの順序を初期設定とする。
- 特定のLandmarkをスキップ可能。
- 観察不可としてマークしたLandmarkは自動的に飛ばす。
- 既に記録済みのLandmarkも自動的に飛ばす。
- 最後まで到達しても未記録項目への入力を強制しない。
- 手動で任意のLandmarkに戻って修正できる。
- 再記録・点移動時に意図しない自動切り替えが起こらないようにする。

Landmark一覧には、記録済み・未記録・観察不可を明示する。

## 7. 画像操作

対応形式：

- JPG
- PNG
- TIFF（可能であれば初期段階から実装）

必要な機能：

- ドラッグ&ドロップによる読み込み
- 複数画像の登録
- マウスホイールによる拡大・縮小
- パン操作
- 画面サイズに合わせた表示
- 明度調整
- コントラスト調整
- ガンマ調整
- RGBチャンネル表示切り替え
- 表示設定のリセット
- アノテーションの表示・非表示
- 画像の一部分を表示するROI機能

すべての画像調整は非破壊的に行うこと。

元画像のピクセル値は変更せず、表示だけを調整する。

**記録した点の座標は常に元画像のピクセル座標とする。**

ズーム、パン、ROI表示、明度調整などによって記録座標が変化してはならない。

## 8. UI構成

### 左側パネル：画像・個体情報

- 登録画像一覧
- ID
- side（L/R）
- species
- sex（M/F/未入力）
- locality
- SL、HL
- observer
- 画像の切り替え
- 個体情報の編集

### 中央：画像ビューア

- 可能な限り広い画像表示領域
- クリックでアノテーション
- ズーム・パン
- 点の追加・移動・削除
- 現在選択中のモードとカテゴリを明示
- マウス位置の画像座標を表示

### 右側パネル：アノテーション

上部に以下のモードを配置する。

- Papillae
- Landmark
- 編集・移動

**Papillaeモード**

4グループのカテゴリボタンを常時表示する。

- a系列：a1～a5
- b：b
- c系列：c1～c9
- その他：cp、d、x、z、os、ot、oi

各カテゴリに現在の計数値と観察状態を表示する。

**Landmarkモード**

9種類のLandmarkボタンを表示する。

- 記録済み・未記録・観察不可を表示
- 「自動で次へ」ON/OFF
- 「スキップ」操作
- 記録後の自動切り替え

下部または別パネルに画像の明度・コントラスト・ガンマ設定を配置する。

### 操作性

- Undo：Ctrl+Z
- Redo：Ctrl+YまたはCtrl+Shift+Z
- Space押下中はパン操作
- Escで選択解除
- Papillaeカテゴリはショートカットキーで切り替え可能
- 大量の点を連続して入力できること
- 入力のたびに画面全体を再描画して操作が重くならないこと

## 9. データ構造

PapillaeとLandmarkを別のデータとして保存する。

### Papillae座標

各点に以下を保存する。

- ID
- side
- image_id
- annotation_session_id
- observer
- category
- point_id
- x_px
- y_px

### Papillaeカテゴリ状態

各画像・セッション・カテゴリについて以下を保存する。

- category
- observation_status
- count
- updated_at

### Landmark座標

- ID
- side
- image_id
- annotation_session_id
- observer
- landmark
- x_px
- y_px
- observation_status

座標の原点は画像左上。

xは右方向、yは下方向を正とする。

画像の元の幅・高さも保存する。

各アノテーション点には一意のIDを付与する。

## 10. CSV・JSON出力

### A. papillae_counts.csv

1行につき1画像・1アノテーションセッション。

出力列：

ID, side, image_id, annotation_session_id, observer, a1, a2, a3, a4, a5, b, c1, c2, c3, c4, c5, c6, c7, c8, c9, cp, d, x, z, os, ot, oi, a_total, c_total, papillae_total

未観察や観察不可のカテゴリはNAとする。

小計しか計算できない場合は、そのことを示すcompleteフラグや観察状態の列を追加する。完全な合計が計算できない場合は、完全合計列をNAとし、観察済みカテゴリの小計は別列に保存する。

### B. papillae_coordinates.csv

1行につき1個のPapilla。

ID、side、category、point_id、XY座標、画像・セッション識別情報を含める。

### C. papillae_status.csv

各画像・セッション・カテゴリの観察状態を出力する。

未観察、計数中、計数完了、観察不可を区別する。

### D. landmarks.csv

各画像・セッションの9ランドマークについて、座標と観察状態を出力する。

未記録のLandmarkも欠測として表現できるようにする。

### E. specimens.csv

個体・画像のメタデータ。

sexはM、F、または欠測とする。

### F. project.json

完全な保存・再読み込み用。

以下を含める。

- 個体・画像情報
- 全Papillae座標
- 全Landmark座標
- カテゴリ定義
- 観察状態
- 計数者情報
- セッション情報
- 画像サイズ
- 保存形式のバージョン

### G. annotated_image.png

元画像にPapillaeとLandmarkを重ねた画像を出力する。

## 11. 保存と共同研究者とのデータ交換

- IndexedDBによる自動保存
- JSONによる手動保存と復元
- 必要に応じて画像を含むZIPバックアップを作成
- 共通カテゴリ設定を研究者間で共有
- 複数研究者のデータを統合
- 同一ID・side・画像の重複を検出
- 同じ画像の別観察者による計数は別セッションとして保持
- 意図しないデータの上書きを防止

初期段階ではクラウド同期やリアルタイム共同編集は不要。

## 12. 必須のテスト

以下を自動テスト・動作確認する。

1. ズーム・パン後も正しい元画像座標が保存される。
2. 画像調整後も既存座標が変化しない。
3. 22カテゴリすべてに点を追加できる。
4. 4グループの表示と計数値が正しく対応する。
5. 点の追加・削除・移動・カテゴリ変更が正常に動作する。
6. Undo/Redoが正しく機能する。
7. Landmarkは原則1カテゴリにつき1点のみ記録される。
8. Landmarkの自動切り替えが正しく機能する。
9. 記録済み・観察不可のLandmarkを自動的にスキップする。
10. Landmarkの自動切り替えをOFFにできる。
11. PapillaeおよびLandmarkの欠測が許容される。
12. 未観察・観察不可・観察済み0個が混同されない。
13. sexのM/F/未入力が正常に保存される。
14. 同一個体のLとRが混同されない。
15. 異なる観察者のセッションが混同されない。
16. CSVの計数値と座標データが一致する。
17. JSONの保存・再読み込み後にデータが完全復元される。
18. 自動保存とブラウザ再起動後の復元が正常に機能する。

## 14. Codexへの実行指示

この仕様書に従い、動作するWebアプリケーションを実装すること。

まず必要なファイル構成とデータモデルを設計し、その後実装・ビルド・テストを進める。

細かな技術的判断は合理的なデフォルトで進め、ユーザーの承認待ちをできる限り少なくする。

提供されたDiASP画像を使って画面表示やクリック操作を確認すること。

README.mdには、起動方法、使用方法、CSV/JSON形式、データ共有方法、GitHub Pages公開手順を記載する。

Windowsの一般的なブラウザで使用できることを確認する。

**最優先事項は、計数の正確性、操作の簡便さ、欠測値の正確な管理、データの安全性、共同研究者間での互換性である。**
